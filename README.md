# The Garden of Mind (Taman Pikiran) - v1.0.0

An aesthetic, single-player cozy web game that merges psychological self-improvement with procedural botanical growth animations. Built entirely using vanilla JavaScript, standard HTML5 Canvas, and modern CSS3 with zero external dependencies.

## 🌟 Features
- **Scientific RIASEC Mapping:** 21 localized psychometric questions connecting user choices to real-world career paths.
- **Bilingual Support:** Instantly toggle between English and Bahasa Indonesia.
- **Cozy Multi-Ad Accessory Studio:** Voluntary rewarded ad integration to unlock premium pots, fences, fireflies, and backgrounds.
- **Responsive & Smart Save:** Fully optimized for mobile/desktop zooms (50%-300%) with automated offline progress tracking via `localStorage`.

## 🌐 Automated Platform Compliance
This game features built-in domain detection logic. When embedded on major game portals (e.g., Poki, CrazyGames), the external monetization link for the premium PDF report is automatically hidden to fully comply with platform guidelines.
